# Portfolio website export

This repository receives static artifacts generated from the single editorial
manifest in `justgithubaccount/justgithubaccount`. It has no second content
manifest, templates or deploy workflow. Do not edit the website files by hand.

After profile review, run its builder with `--pages-dir` pointing at an isolated
checkout of this repository. Compare every generated byte and the manifest and
generator digests in `build-info.json` to the reviewed profile source commit.
Record that exact commit in the separate website Draft PR.

```sh
python3 scripts/audit.py --site-only --root .
python3 -m http.server 8765 --bind 127.0.0.1
```

`scripts/audit.py` is copied from the profile source. Its CI checks export hashes,
links, SVG/HTML safety, indexing state and accidental-disclosure patterns without
credentials or a cross-repository token. It cannot prove operator approval.

The current export is a `RELEASE_APPROVED` candidate in a Draft PR, following
operator acceptance of the V1 content and design. This is **not** evidence of
live publication, deployment or indexing. Merge, Pages settings and final
publication require separate explicit authorization and live-URL verification.
